# Pizza Sales Analytics Dashboard

## Project Overview

This project analyzes pizza sales data using Power BI to understand revenue performance, order patterns, and customer purchasing trends.

## Project Objectives

* Track total revenue and order performance.
* Identify peak sales days and hours.
* Analyze sales by pizza category and size.
* Compare pizza product performance.
* Discover trends to support business decisions.

## Tools Used

* Power BI
* DAX
* Data Cleaning
* Data Visualization

## Key Insights

* Peak ordering hours were 12 PM–1 PM and 5 PM–6 PM.
* Thursday and Friday recorded higher sales activity.
* Sales patterns were analyzed by pizza category, size, and product.

## Dashboard Features

* Key Performance Indicators (KPIs)
* Daily and hourly sales trends
* Category and size analysis
* Best-selling and underperforming pizzas
